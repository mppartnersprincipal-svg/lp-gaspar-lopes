Botao em caps largas da Gaspar Lopes; use "primary" para o CTA principal (claro sobre fundo escuro), "outline" para secundario.

```jsx
<Button variant="primary" size="lg">Agendar horario</Button>
<Button variant="outline">Ver colecao</Button>
```

Variantes: primary, navy, outline, ghost. Tamanhos sm/md/lg. Rotulos curtos, caixa alta automatica.
